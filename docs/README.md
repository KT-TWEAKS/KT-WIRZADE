# Documentação do KT WIRZADE

Esta pasta reúne material público de apoio ao projeto:

- `imagens/`: capturas reais da interface usadas na documentação.
- `../RELEASE-1.0.1.md`: notas detalhadas do hotfix.
- `../CHANGELOG.md`: histórico técnico de correções.

O registro de APBX verificados é mantido no projeto de licenciamento da organização. O aplicativo consulta a API pública de verificação por `ProductCode` e/ou SHA-256; ele não considera um playbook oficial apenas por estar hospedado em um link conhecido.

A release pública deve conter apenas arquivos necessários para usuários e contribuidores; validações internas ficam no repositório privado.
