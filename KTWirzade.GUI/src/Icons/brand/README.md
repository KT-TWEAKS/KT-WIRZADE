# KT TWEAKS brand assets

- `kt-tweaks-wordmark.svg` is the editable vector logo for websites and documents.
- `kt-tweaks-wordmark.png` is a transparent preview of the wordmark.
- `kt-tweaks-icon.svg` is the scalable square app mark.
- `../ico.ico` is the multi-size Windows icon currently embedded in KT WIRZADE and shown in its window title bars.
- `kt-tweaks-icon.png` is the 512 px transparent-background icon source.

Palette: violet `#51317F` → `#8050C7`, coral accent `#F0645A`, ink `#25212B`.
Typography: Segoe UI with Inter and Arial fallbacks.
