Documentacao da API

Endpoints REST para verificacao e gestao de playbooks KT WIRZADE.

Base URL

http://localhost:3000/api

Todos os endpoints retornam JSON. Rate limit: 60 requisicoes/minuto.

GET /api/verify Verificar playbook

Verifica a autenticidade de um playbook usando ProductCode ou hash SHA256.

Parametros (Query String)

prodID string ProductCode do playbook (ex: KTW-DEBLOAT-001)
hash string Hash SHA256 do arquivo

Exemplo de Requisicao

GET /api/verify?prodID=KTW-DEBLOAT-001

Resposta (200 OK)

{ "verified": true, "status": "verified", "playbook": { "id": "example-001", "name": "KT WIRZADE Debloat", "author": "KT Wirzade Team", "version": "1.0.0", "description": "Playbook oficial de debloat...", "website": "https://ktwirzade.com", "git": "https://github.com/kt-wirzade/...", "verifiedAt": "2026-01-01T00:00:00Z" } }

Resposta - Nao Encontrado

{ "verified": false, "status": "unverified", "playbook": null, "message": "Playbook nao encontrado na base de dados." }
GET /api/playbooks Listar playbooks

Lista todos os playbooks verificados. Suporta busca e filtro por tag.

Parametros (Query String)

search string Termo de busca (nome, descricao, autor)
tag string Filtrar por tag (ex: debloat, gaming)

Exemplo de Requisicao

GET /api/playbooks?search=debloat&tag=otimizacao

Resposta (200 OK)

{ "playbooks": [ { "id": "example-001", "name": "KT WIRZADE Debloat", "author": "KT Wirzade Team", "version": "1.0.0", "verified": true, "tags": ["debloat", "windows"] } ], "total": 1 }
GET /api/playbooks/:id Detalhes do playbook

Retorna os detalhes completos de um playbook especifico.

Parametros (URL)

id string ID do playbook (ex: example-001)

Resposta (200 OK)

{ "playbook": { "id": "example-001", "productCode": "KTW-DEBLOAT-001", "name": "KT WIRZADE Debloat", "author": "KT Wirzade Team", "version": "1.0.0", "description": "...", "verified": true, "verifiedAt": "2026-01-01T00:00:00Z", "hash": "a1b2c3d4...", "tags": ["debloat"] } }

Resposta - Nao Encontrado (404)

{ "error": "Playbook nao encontrado." }
POST /api/playbooks/register Registrar playbook (admin)

Registra um novo playbook na base de dados. Requer chave de administrador.

Headers

X-Admin-Key string Chave de administrador (obrigatorio)
Content-Type string application/json

Body (JSON)

productCode string * ProductCode unico (obrigatorio)
name string * Nome do playbook (obrigatorio)
author string Autor do playbook
version string Versao (ex: 1.0.0)
description string Descricao do playbook
website string URL do site oficial
git string URL do repositorio GitHub
hash string Hash SHA256 do arquivo
tags string[] Lista de tags

Exemplo de Requisicao

POST /api/playbooks/register Headers: { "X-Admin-Key": "ktwirzade-admin-2026", "Content-Type": "application/json" } { "productCode": "KTW-CLEAN-004", "name": "KT WIRZADE System Clean", "author": "KT Wirzade Team", "version": "1.0.0", "description": "Limpeza completa do sistema", "tags": ["limpeza", "sistema"] }

Resposta (201 Created)

{ "playbook": { "id": "plb-a1b2c3d4", "productCode": "KTW-CLEAN-004", "name": "KT WIRZADE System Clean", "verified": false }, "message": "Playbook registrado com sucesso." }
